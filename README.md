# CodeAlpha HR Analytics Dashboard

## Project Overview

This project is an interactive Human Resources Analytics Dashboard developed using Microsoft Power BI for CodeAlpha Internship Task 2.

It analyzes workforce information, recruitment performance, employee satisfaction, and hiring trends to support HR decision-making.

## Objectives

* Track employee and recruitment metrics.
* Analyze employee turnover.
* Compare employee satisfaction and performance by department.
* Monitor applications, hires, and average time to hire.
* Explore future hiring needs using forecasting.

## Tools and Technologies

* Microsoft Power BI Desktop
* Power Query
* DAX
* Microsoft Excel

## Dashboard Features

### Workforce KPIs

* Total Employees
* Active Employees
* Employee Turnover Rate

### Recruitment KPIs

* Total Hires
* Total Applications
* Average Time to Hire

### Visualizations

* Monthly Recruitment Trends
* Employee Satisfaction and Performance by Department
* Three-point hiring forecast

## Dataset

This project uses a sample dataset containing employee information and monthly recruitment records. The data is intended for practice and demonstration purposes.
